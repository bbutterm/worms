# Спрайты

Содержимое этой папки, кроме `raw/`, **генерируется** — руками ничего
не правим:

```bash
python3 tools/build_assets.py
```

Скрипт читает распакованные рипы из `raw/`, переводит их в формат, который
понимает Phaser, и заодно выписывает размеры кадров в `src/core/sprite-meta.js`.

## Откуда что берётся

| Что в игре                 | Источник в `raw/`                          |
|----------------------------|--------------------------------------------|
| `worm_idle/walk/fall.png`  | `general/Worms/wbrth1, wwalk, wfall`       |
| `marker_0/1.png`           | `general/Misc/arrowdnr, arrowdnb`          |
| `grave.png`                | `general/Misc/grave1`                      |
| `proj_bazooka.png`         | `general/Weapons/missile` (32 поворота)    |
| `proj_grenade.png`         | `general/Weapons/grenade`                  |
| `proj_cluster.png`         | `general/Weapons/cluster`                  |
| `proj_bomblet.png`         | `general/Weapons/clustlet`                 |
| `proj_mole.png`            | `general/Weapons/mbbomb`                   |
| `fx_flash.png`             | `general/Effects/circl100`                 |
| `fx_smoke.png`             | `general/Effects/smklt100`                 |
| `icon_*.png`               | `general/Weapon Icons/*.1.png`             |
| `terrain/<тема>/*`         | `terrain/Terrain/<Тема>/soil,grass,back,gradient` |

## Что важно знать про исходники

* **Альфы в рипах нет.** Прозрачность закодирована индексом 0 палитры
  (RGB 128,128,192). Конвертацию делает `tools/wa.py`.
* **Анимации — вертикальные ленты** кадров 60×60 (у части эффектов крупнее).
  Сборщик режет их и складывает в горизонтальные ленты для Phaser.
* **Все анимации червяка кропаются одним общим боксом.** Иначе спрайт
  прыгал бы при переключении анимации. Точка привязки ног уезжает
  в `sprite-meta.js`.
* **У снарядов кадры — это 32 предрассчитанных поворота**, а не анимация.
  Кадр 7 смотрит вправо, дальше по часовой с шагом 11.25°. Выбор кадра —
  `rotFrame()` в `src/core/assets.js`.
* **Тайлящаяся ширина текстур ландшафта — ровно 128 px.** Всё, что правее
  в `grass.png`, — служебные блоки для вертикальных кромок, в бесшовный
  повтор они не годятся. `soil.png` тайлится целиком (256×256).
* **Градиент неба рассчитан на карту выше экрана**, поэтому по высоте он
  не ужимается — нижняя, почти чёрная часть просто остаётся за кадром.

## Если файла нет

Любого файла может не быть — движок молча подставит цветной плейсхолдер
(запасные цвета лежат в `fallback` каждой темы в `src/core/biomes.js`),
и игра останется играбельной.
