# Спрайты

Клади файлы **прямо сюда**, с этими именами. Любого файла может не быть —
движок молча подставит цветной плейсхолдер, игра останется играбельной.
Пути и размеры описаны в `src/core/assets.js` (там же их можно переименовать).

| Файл                   | Что это                                   | Рекомендуемый размер |
|------------------------|-------------------------------------------|----------------------|
| `worm.png`             | боец (тонируется в цвет команды)          | 24×32 или кратно     |
| `worm_walk.png`        | спрайтшит ходьбы (необязательно)          | кадр 32×40           |
| `bg_sky.png`           | фон-небо, тайлится                        | 1280×720             |
| `bg_hills.png`         | дальние холмы (параллакс 0.4)             | ≥1280×340, бесшовно  |
| `terrain_meadow.png`   | текстура земли, биом «Луговой остров»     | 128×128, бесшовно    |
| `terrain_desert.png`   | текстура земли, биом «Пустынный шельф»    | 128×128, бесшовно    |
| `terrain_tundra.png`   | текстура земли, биом «Ледяная гряда»      | 128×128, бесшовно    |
| `terrain_volcano.png`  | текстура земли, биом «Вулканический кратер» | 128×128, бесшовно  |
| `proj_bazooka.png`     | снаряд базуки                             | 16×16                |
| `proj_grenade.png`     | граната                                   | 16×16                |
| `proj_cluster.png`     | кассетная бомба                           | 16×16                |
| `proj_bomblet.png`     | бомблет из кассеты                        | 12×12                |
| `proj_drill.png`       | бур                                       | 16×16                |
| `explosion.png`        | спрайтшит взрыва                          | кадр 96×96           |
| `crosshair.png`        | прицел (пока не используется)             | 32×32                |

Замечания:

* `worm.png` тонируется через `setTint` в цвет команды — лучше рисовать
  в светло-сером/белом, иначе тинт будет грязным. Если хочешь готовые
  цветные спрайты команд — скажи, разведу по ключам `worm_team0/1`.
* Текстуры земли накладываются как `repeat`-паттерн поверх градиента
  и обрезаются по маске, поэтому важна бесшовность, а не размер.
* Спрайтшиты режутся по фиксированной сетке кадров (размеры — в
  `SHEETS` в `src/core/assets.js`). Количество кадров определяется
  автоматически.
